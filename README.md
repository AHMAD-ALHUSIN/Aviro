# محمل الفيديوهات — تطبيق أندرويد محلي بالكامل

تطبيق بسيط يعمل بالكامل على جهاز المستخدم (بدون أي سيرفر)، فيستخدم شبكة
الجوال/واي فاي الخاصة به مباشرة — وبالتالي لا تظهر مشكلة "Sign in to confirm
you're not a bot" التي تحدث مع سيرفرات مراكز البيانات مثل Azure.

## القيود المقصودة (لتبسيط البناء)

- لا يُستخدم `ffmpeg` داخل التطبيق، لذلك:
  - خيارات الجودة المعروضة هي فقط الصيغ التي تجمع فيديو + صوت في ملف واحد
    مباشرة من يوتيوب (عادة حتى 720p).
  - خيار "صوت فقط" يحفظ الملف الصوتي بصيغته الأصلية (غالبًا m4a) بدون تحويل
    لـ MP3 — يعمل في أي مشغل صوت عادي.
- لاحقًا يمكن إضافة `ffmpeg` لدعم دمج 1080p+ وتحويل MP3، لكن هذا يعقّد عملية
  البناء (Build) بشكل كبير.

## طريقة البناء (الأسهل: عبر GitHub Actions، مجانًا بالكامل)

بناء تطبيق أندرويد محليًا يحتاج بيئة ثقيلة (Android SDK/NDK) قد لا تتحمّلها
أجهزة بسيطة. الأسهل هو خلي GitHub يبني الـ APK لك مجانًا عبر GitHub Actions.

### الخطوات:

1. أنشئ حساب على [github.com](https://github.com) إذا ما عندك واحد.
2. أنشئ مستودع (Repository) جديد، خاص أو عام، باسم مثلاً `ytdownloader`.
3. ارفع كل الملفات الموجودة في هذا المجلد إلى المستودع (حافظ على نفس البنية،
   بما فيها مجلد `.github/workflows/`):
   ```
   ytdownloader/
   ├── main.py
   ├── buildozer.spec
   ├── README.md
   └── .github/
       └── workflows/
           └── build.yml
   ```
   أسهل طريقة للرفع: من صفحة المستودع على GitHub اضغط "Add file" →
   "Upload files"، واسحب الملفات (حافظ على أسماء المجلدات).

4. بمجرد الرفع، اذهب لتبويب **Actions** في أعلى صفحة المستودع. سيبدأ البناء
   تلقائيًا (يأخذ عادة 10-20 دقيقة أول مرة).

5. بعد انتهاء البناء بنجاح (علامة ✅ خضراء)، افتح المهمة (Job) واذهب لأسفل
   الصفحة لقسم **Artifacts**، وحمّل `ytdownloader-apk` — هذا ملف مضغوط يحتوي
   ملف الـ APK بداخله.

6. فك الضغط، وانقل ملف `.apk` إلى جوالك الأندرويد (عبر كيبل USB، بريد
   إلكتروني لنفسك، أو رفعه على Google Drive وتنزيله من الجوال).

7. على الجوال: اضغط على ملف الـ APK لتثبيته. أول مرة سيطلب منك أندرويد
   تفعيل خيار **"تثبيت من مصادر غير معروفة"** لهذا التطبيق تحديدًا — وافق
   عليه (هذا طبيعي لأي تطبيق خارج متجر Google Play).

8. افتح التطبيق، الصق رابط فيديو، اضغط "فحص الجودات المتوفرة"، اختر
   الجودة، ثم "تحميل". الملف يُحفظ في:
   ```
   Download/YTDownloader/
   ```
   على ذاكرة جوالك.

## ملاحظة عن الاستقرار

هذا الحل يحل مشكلة الحظر بسبب IP السيرفر نهائيًا (لأن التحميل يصير من شبكة
كل مستخدم بنفسه). لكن يبقى احتمال بسيط أن يوتيوب يغيّر شيء في نظامه يكسر
`yt-dlp` مؤقتًا لجميع المستخدمين حول العالم — في هذه الحالة الحل هو تحديث
مكتبة `yt-dlp` في `buildozer.spec` وإعادة البناء (رفع تحديث بسيط في GitHub
يشغّل Actions من جديد تلقائيًا وينتج APK جديد).

## توزيع التطبيق لاحقًا (اختياري)

- **للاستخدام الشخصي أو لعدد محدود من الناس تعرفهم:** التوزيع اليدوي لملف
  APK (كما في الخطوات أعلاه) كافٍ تمامًا.
- **للتوزيع العام عبر Google Play:** يوتيوب/جوجل غالبًا يرفضون هذا النوع من
  التطبيقات في المتجر الرسمي، فهذا الخيار غير مناسب لتطبيقات تحميل يوتيوب.
